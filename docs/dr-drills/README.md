# DR Drill Evidence

This directory stores dated backup/restore drill evidence generated by:

```bash
./scripts/run-db-restore-drill.sh --execute
```

Keep entries placeholder-free. Phase 0 strict gates validate the latest
`*.md` file here with:

```bash
./scripts/verify-dr-drill-evidence.sh
```

Do not commit database dumps, connection strings, customer data, screenshots
with secrets, or raw provider credentials.
